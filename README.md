# Anthony David

**Full-Stack Engineer — Python, TypeScript/React, APIs and real-time systems.**

I build production products end to end: Python services (FastAPI, Flask, SQLAlchemy), React and TypeScript frontends, and the infrastructure that keeps them running — PostgreSQL, Redis, Docker, Kubernetes, OIDC and RBAC.

Most of my work is in systems where several parties must agree. Healthcare interoperability, pharmacy and hospital operations, payments, and real-time tooling. The pattern is the same each time: read the existing system properly, find where its data model and its business process disagree, and ship the smallest change that makes them agree — with tests that prove it.
